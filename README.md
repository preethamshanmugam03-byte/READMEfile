Hi Team,

I’ve created a SOAP Test Automation workflow using Jenkins Orchestrators and a Chrome Extension to simplify and reduce the manual effort involved in triggering the Multiset SOAP tests.

With this automation, you can select the required test path/environment and trigger the required Multiset jobs in parallel, instead of manually opening and triggering each Multiset job individually. The extension will also automatically open the relevant Multiset Jenkins pages once the Orchestrator build is triggered.

The automation currently supports:

Path 1: ST1 / PERF
Path 2: ST2
Path 3: IA / MO
